# AG Premier Transportation App Prototype

This is a standalone responsive web-app prototype.

Included:
- Home / brand presentation
- Services
- Fleet gallery placeholders
- About section
- Interactive monthly booking calendar
- Time-slot selector
- Booking/contact form
- Pickup/drop-off details
- Passenger count
- Service type + vehicle preference
- Customer notes
- Local booking confirmation + confirmation number
- Mobile-friendly navigation

Important:
This prototype stores submitted booking requests in the customer's browser using localStorage. For a production launch, connect the form to:
1. A secure backend/database
2. Email and/or SMS notifications
3. Admin booking dashboard
4. Online payments/deposits
5. Google Calendar or Outlook Calendar
6. Automated confirmations/reminders
7. Real vehicle photos
8. Your actual phone/email/social links

To preview:
Open index.html in any modern web browser.
